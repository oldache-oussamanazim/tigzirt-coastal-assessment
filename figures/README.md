# Figures

This repository section catalogs the visual evidence and technical illustrations extracted directly from the Tigzirt coastal assessment technical report (`rapport_stage_tigzirt.pdf`). These assets provide empirical and visual support for the field survey, geomorphological analysis, and engineering evaluations conducted on-site.

## Inventory Overview

The imported figures are categorized into the following thematic sets corresponding to the report's structure:

* **Study Area & Regional Context
* **Field Survey Operations
* **Shoreline Evolution & Temporal Analysis
* **Coastal Infrastructure & Environmental Observations

---
*All assets originate from verified field data and report documentation.*
