# Figures

Place only figures already included in the submitted field report, or figures subsequently generated from verified original data, in this directory.

Suggested organization:
- `study_area/` — study-area location and regional context.
- `field_survey/` — photographs of the Topcon GM-52, prism, field setup, and observations.
- `shoreline_evolution/` — Google Earth comparison figure and any later verified shoreline visualizations.
- `coastal_infrastructure/` — photographs of gabions, the backshore wall, stream outlets, and port structures.

Use descriptive filenames and captions. Do not describe report-derived figures as newly generated GIS results. Do not add survey-derived maps until the original AutoCAD or coordinate files have been recovered and checked.
